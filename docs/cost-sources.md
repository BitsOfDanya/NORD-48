# Источники экономических данных

Ни одно число в этом документе не является ценой 2026 года и не
используется backend'ом как значение по умолчанию (см.
[cost-effectiveness.md](cost-effectiveness.md) — `satellite_unit_cost_rub`
и остальные поля `CostAssumptions` всегда `None`, пока пользователь не
введёт их сам). Это справочные, датированные публичные ориентиры для
заполнения формы — каждый явно подписан источником в UI, ни один не
подставляется молча.

| Организация | АФК «Система» / Sitronics / «Спутникс» |
| Кто сказал | Алексей Катков, председатель совета директоров «Ситроникса», управляющий партнёр АФК «Система» |
| Дата | 7 декабря 2021 |
| Источник | [Ведомости, «Компания Евтушенкова планирует запустить в космос до 100 спутников»](https://www.vedomosti.ru/technology/articles/2021/12/06/899290-kompaniya-evtushenkova) |
| Показатель | Стоимость выведения на орбиту малого КА — около 10 млн ₽; рыночная стоимость производства такого спутника — примерно такая же |
| Значение | ~10 млн ₽ производство + ~10 млн ₽ выведение = ~20 млн ₽ за спутник «под ключ» |
| Применимость | Малые/сверхмалые КА класса «Спутникс» (1–200 кг), рыночная оценка на конец 2021 |
| Ограничения | Не тарифная оферта, не текущая цена; курс рубля, себестоимость компонентов и рынок пусковых услуг с 2021 года изменились. Не пересчитывать в цену 2026 года без официального метода. |

Тот же источник для флота: «стоимость создания спутникового флота из 100
аппаратов составит порядка 2 млрд ₽» — что примерно совпадает с 100 × 20
млн ₽, то есть внутренне согласовано с построчной оценкой выше.

## Как это используется в продукте

`docs/cost-effectiveness.md` описывает `CostAssumptions` — все поля
(`satellite_unit_cost_rub`, `launch_fixed_cost_rub`,
`launch_capacity_satellites`, ...) по умолчанию `None`/`0`, что
соответствует **ресурсному режиму** (только число аппаратов/партий
запуска, без рублей). В UI пользователь может нажать «Заполнить из
исторического ориентира (Sitronics, 2021)» — это ЯВНОЕ действие,
подставляющее ~10 млн ₽ производство + ~10 млн ₽ запуск с видимой
подписью источника и предупреждением «Оценка ориентировочная, не
является коммерческим предложением», либо ввести свои значения. Ни один
пресет не применяется автоматически.
