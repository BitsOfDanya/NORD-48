# Полный прогон отказоустойчивого поиска — 12 сентября 2026

Прогон завершён за 1240,47 с (20 мин 40 с). Проверены 150 конфигураций
RAAN/phase и 240 кандидатов внутреннего поиска отказов, включая частичные
наборы при построении criticality-seed. Результаты относятся к исходной
расчётной модели с горизонтом 86400 с и шагом 120 с.

## Прямое сравнение с исходной таблицей

Фиксированный профиль `03_satellite_outages`, доступность за полные сутки.

## Устойчивость по банкам отказов

Для каждого набора берётся минимальная доступность среди C65, C70, C72
на интервале 06:00–24:00. CVaR10 — среднее по худшим 10 % массы банка,
с учётом дробной массы граничного случая. У всех случаев одинаковый вес.

| Метрика | Исходная | Найденная | Прирост |
| --- | --- | --- | --- |
| CVaR10, окончательный обучающий банк | 66,910 % | 70,906 % | +3,996 п.п. |
| Минимум, окончательный обучающий банк | 66,296 % | 70,556 % | +4,259 п.п. |
| CVaR10, holdout | 65,630 % | 70,519 % | +4,889 п.п. |
| Минимум, holdout | 65,370 % | 70,185 % | +4,815 п.п. |

Обучающий банк: 19 различных наборов — 1 фиксированный, 8 случайных,
6 коррелированных и 4 adversarial. Исходная и найденная конфигурации
сравнены на одном окончательном банке.

Holdout: 50 различных наборов — 8 новых случайных и 42 коррелированных.
Пересечений с обучающим банком нет; в каждом наборе ровно 10 спутников.
Коррелированные наборы генератора не зависят от seed, поэтому для holdout
запрошены все 48 окон, после чего исключены 6 обучающих. Эта проверочная
выборка содержит большую долю коррелированных отказов, чем обучающая;
разность train/holdout CVaR (0,388 п.п.) не является чистой оценкой
переобучения при одинаковом распределении случаев.

Это результат на проверенных наборах, а не гарантия для всех сочетаний
10 отказов. Уровень 90 % при отказах не достигнут.

## Воспроизведение

Команда из корня репозитория:

```sh
backend/.venv/bin/python scripts/run_failure_robust_experiment.py
```

Настройки: toroidal DE, seed=42, четыре переменные P2/P3 RAAN/phase в
[0, 360), budget=25, два рестарта, два adversarial-раунда. В каждом
внутреннем раунде — 120 оценок, три запрошенных набора, минимальное
swap-расстояние 2. В каждом раунде приняты два набора, третий отклонён
по условию разнообразия. Маршрутизация — `minimum_hops`.

Полные локальные артефакты:
`data/results/failure_robust/20260912T052436891468Z/`.
Здесь сохранены входные сценарии, настройки, история, `result.json`,
`summary.json`, `full-day-comparison.json`, `optimized-normal.json`
и `optimized-fixed-failure.json`. Каталог результатов исключён из Git
существующими правилами проекта; этот отчёт и скрипт воспроизведения
доступны для отслеживания в Git.
