# CatBoost в оптимизаторе

В интерфейсе: «Оптимизатор» → «Геометрия орбит» → выбор алгоритма →
«CatBoost · обучение в ходе поиска». API: `algorithm: "catboost"`.
Существующие алгоритмы и их значения по умолчанию сохранены.

### Быстрый поиск без обучения

Выберите «CatBoost · сохранённая модель · быстрый поиск»
(`algorithm: "catboost_pretrained"`, режим `normal`). Backend загружает
последнюю совместимую модель из каталога артефактов, прогнозирует 8192
варианта и точно оценивает baseline плюс до 15 лучших прогнозов.
Бюджет точных кандидатов ограничен `min(budget, 16)`; top-5 повторно
пересчитываются. Модель не обучается и не изменяется. Все итоговые
метрики остаются результатами точного симулятора.

Совместимость проверяется по полному сценарию, порядку изменяемых
параметров, фиксированным углам, стратегии маршрутизации и целевой метрике.
Текущий артефакт подходит для `01_full_constellation`, `minimum_hops`,
параметров P2 RAAN, P3 RAAN, P2 phase, P3 phase именно в этом порядке.
Обучение охватывает углы [0, 360); поиск допускает более узкие границы.
При отсутствии совместимой модели запуск сообщает ошибку; автоматического
обучения нет. Чтобы обновить модель, повторите команду обучения ниже.

По умолчанию каталог — `ml/artifacts` в корне репозитория. Оба Docker Compose
файла уже подключают `./ml/artifacts:/models:ro` к backend и задают
`NORD48_CATBOOST_DIR=/models`. Запуск: `docker compose up -d --build`;
production: `docker compose -f docker-compose.prod.yml up -d --build`.
Внутри должны находиться каталоги
`catboost-*/` с `report.json` и `model.cbm`. Модели не включены в Docker-образ:
они читаются из bind mount. Исходная модель включена в git и доступна после
клонирования репозитория. Новые локальные модели нужно переносить в `ml/artifacts`
на сервере отдельно либо явно добавлять в git. После добавления нового
артефакта следующий запуск подхватит его без перезапуска сервиса.

Первые 32 кандидата (или весь бюджет, если он меньше) считаются точно.
CatBoostRegressor обучается предсказывать скалярную целевую функцию
выбранного режима по sin/cos изменяемых RAAN/phase. Далее каждая итерация
ранжирует 1024 случайных конфигурации: семь лучших прогнозов и один
случайный кандидат проверяются точным симулятором. Через каждые восемь
новых результатов модель переобучается на накопленной выборке.
Модели из разных сценариев, режимов и банков отказов не смешиваются.
Досрочная остановка по target может завершить запуск до обучения.

Бюджет учитывает точные оценки кандидатов; дополнительно top-5 проходят
повторную точную проверку. Все опубликованные метрики, Pareto и рекомендации
основаны на точных расчётах. Число обучений возвращается как `surrogate_fits`
и отображается в итогах обычного поиска. Превосходство над DE/random
не гарантируется; для сравнения нужны одинаковые бюджеты и несколько seed.

## Отдельное обучение

```bash
cd backend && uv sync && cd ..
backend/.venv/bin/python scripts/train_catboost.py --samples 256 --holdout 64
```

Скрипт генерирует независимые случайные конфигурации полного штатного
сценария, получает exact labels за сутки (720 шагов), обучает модель и
считает MAE/RMSE на отдельной holdout-выборке. Для сравнения сохраняется
MAE постоянного прогноза среднего train. Holdout не используется в fit.
В `ml/artifacts/catboost-*/` сохраняются `model.cbm`, `dataset.jsonl`
с разделением train/holdout и `report.json` с настройками и полным сценарием.
Исходный обученный артефакт `catboost-20260912T190729172811Z` включён в git
вместе с моделью, отчётом и датасетом. Новые артефакты по умолчанию исключены
из git. Для повторного обучения на новой
выборке можно изменить seed или размер; каждый запуск создаёт новый каталог.

Сохранённая модель используется быстрым режимом для совместимого штатного
сценария. Вариант «обучение в ходе поиска» обучает собственную модель при
каждом запуске. В backend CatBoost входит в основные зависимости, поэтому
устанавливается и при Docker-сборке; у заготовки `ml/` доступен
`uv sync --extra boosting`.

Параметры регрессора сверены с
[документацией CatBoost](https://catboost.ai/docs/en/concepts/python-reference_catboostregressor).

## Выполненное обучение

Seed 42, 256 train + 64 holdout, штатная полная группировка:
MAE = 0,08143 (8,14 п.п. доступности), RMSE = 0,09306;
MAE постоянного среднего train = 0,15560 (15,56 п.п.).
Артефакты локального прогона: `ml/artifacts/catboost-20260912T190729172811Z/`.
Это проверка качества прогноза; ускорение поиска и превосходство над DE
по этим метрикам не установлены.

Быстрый режим проверен отдельно на полной группировке, `minimum_hops`,
seed 42, четыре угла, stop_on_target=False (время всей функции сервиса):

| Алгоритм | Точных кандидатов + повторная проверка | Время | Лучшая worst availability |
| --- | --- | --- | --- |
| Сохранённый CatBoost | 16 + 5 | 8,48 с | 97,92% |
| Random | 100 + 5 | 41,82 с | 99,17% |

В этом одиночном прогоне ускорение составило 4,93 раза ценой 1,25 п.п.
качества найденной конфигурации. Это не гарантия для других seed и условий;
время предварительного обучения сюда не включено. Обучение выполняется
отдельно и затем используется повторно.
