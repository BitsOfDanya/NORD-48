# Минимальный размер группировки для target ≥90%

Использует тот же greedy-жадный проход, что и
[deployment-planner.md](deployment-planner.md) (см. там методику и её
ограничения) — минимальный размер это просто первая точка на той же
кривой, где `worst_availability` пересекает `target_availability`.

## Результат

Прогон: `01_full_constellation`, `minimum_hops`, полный проход 1..48,
`seed`-независимый (алгоритм полностью детерминированный, случайности нет).

| N | Worst availability | Target ≥90% |
| --- | --- | --- |
| 43 | 87,64 % | FAIL |
| 44 | 89,72 % | FAIL |
| **45** | **91,53 %** | **PASS** |
| 46 | 93,33 % | PASS |
| 47 | 95,00 % | PASS |
| 48 | 96,67 % | PASS |

**Минимальный размер группировки, при котором достигается target ≥90 % —
45 аппаратов**, при оптимальном (найденном жадным алгоритмом)
распределении: ровно **15 спутников на каждую из 3 плоскостей**. Переход
резкий — потеря всего одного дополнительного спутника сверх этих 45 (то
есть N=44) уже опускает худшего клиента ниже цели, до 89,72 %.

Точная формулировка, без завышения точности: *«При доступных степенях
свободы (выбор активного подмножества спутников; RAAN/phase фиксированы
на значениях `01_full_constellation`) минимальный размер группировки, при
котором жадный алгоритм находит конфигурацию с target ≥90 %, — 45
аппаратов, распределённых поровну по трём плоскостям»*. Это НЕ означает,
что любые случайные 45 спутников дают ≥90 % — только то, что удачно
выбранные 45 могут. Обратный, более суровый вопрос («любые ли 45
достаточно устойчивы») — это вопрос отказоустойчивости (N-k), не
развёртывания, и им не подменяется.

## Инженерный вывод

- Существующий baseline `01_full_constellation` (48/48 спутников) даёт
  запас в 3 избыточных аппарата над найденным минимумом (48 vs 45) — это
  запас прочности примерно 6% группировки сверх строго необходимого для
  штатной цели.
- Дальнейшее сокращение группировки (например, для снижения стоимости
  развёртывания) физически возможно вплоть до 45 аппаратов при условии
  их равномерного распределения по плоскостям — но не более, в рамках
  текущей архитектуры (3 плоскости, эти RAAN/phase, эта высота/наклонение).
- Ниже 45 — target 90% в штатном режиме недостижим в исследованном
  диапазоне подбором подмножества спутников; для более низких N нужны
  либо другие RAAN/phase, либо другая архитектура (больше плоскостей,
  другая высота), либо смягчение цели.
